# Company styles

The framework in [../00-interview-playbook.md](../00-interview-playbook.md) works everywhere.
This folder covers what each company *weights differently* — which is usually the difference
between a hire and a down-level.

## The one-table comparison

| | Amazon | Meta | Google | Netflix | Startups |
|---|---|---|---|---|---|
| **Round length** | 45–60 min | 45 min (often ×2) | 45 min | 45–60 min | 45–90 min |
| **Behavioural woven in?** | **Yes, in every round** | No — separate round | Lightly | Yes, heavily | Usually |
| **Signature element** | Leadership Principles + **Bar Raiser with veto** | Two tracks: product architecture vs infra system design | Depth-first probing, open-ended prompt | Senior-only bar, high context, judgement | Pragmatism, cost, "what would you ship first" |
| **Loves** | Operational excellence, cost, ownership, customer obsession | Scale numbers, product sense, clear trade-offs | Fundamentals, algorithms inside the design, data structures | Freedom-and-responsibility judgement, real production stories | Shipping, prioritisation, doing more with less |
| **Common failure** | Vague/hypothetical answers; no LP evidence | Running out of time; no depth | Hand-waving; can't go deeper when pushed | Not senior enough in judgement | Over-engineering for scale that doesn't exist |

## Universal, everywhere

Whatever the badge on the door:

1. **Drive the conversation.** The gap between hire and strong-hire at senior is almost never
   more knowledge.
2. **Numbers, not adjectives.**
3. **Cover failure and cost unprompted.** Both are explicitly in 2026 rubrics.
4. **Concede fast when challenged**, patch the design, keep moving.
5. **Level calibration is real.** The same answer that is a strong L4/E4 performance is a
   down-level for L6/E6 — because the expectation is scope and judgement, not correctness.
